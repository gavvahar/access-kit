# @gavvahar/access-kit-ui

Package scaffold for the Web Components shared by ClearRead and SoundSight.
Versioned independently from the Python package with `web-vX.Y.Z` tags.

Themes, fonts, settings, utilities, and the demo are planned for Phase C.
No UI components are implemented yet. Publishing is disabled until the first
reviewed web release.

From the repo root: `npm run check --workspace web`.
